## Forschungsschwerpunkte und Expertise

Dr. Oulabi war ehemaliger Mitarbeiter des [Chair of Information Systems V: Web-based Systems](https://www.uni-mannheim.de/dws/research/focus-groups/web-based-systems-prof-bizer/) von [Prof. Dr. Christian Bizer](https://www.uni-mannheim.de/dws/people/professors/prof-dr-christian-bizer/). Seine Forschung konzentriert sich auf die Erweiterung von Domänenübergreifenden Wissensdatenbanken mithilfe strukturierter Webdaten.

**Kernbereiche:**

- **Knowledge Base Completion:** Vervollständigung von Wissensdatenbanken.
- **Web Table Data Consolidation:** Konsolidierung von Daten aus Web-Tabellen.
- **Long-Tail Entity Extraction:** Extraktion von seltenen (Long-Tail) Entitäten.
- **Time-Dependent Web Data Fusion:** Fusion von zeitabhängigen Webdaten.
- **Weak Supervision:** Einsatz von schwacher Überwachung zur Datenannotation.

## Forschungsergebnisse und Ressourcen

### Veröffentlichte Datensätze

Diese Datensätze dienen der Entwicklung und Evaluierung von Methoden im Umgang mit komplexen Webdaten.

- **[Time-Dependent Ground-Truth Dataset](http://webdatacommons.org/TDGT/)**: Enthält die Ground Truth von zeitabhängigen Daten aus verschiedenen Domänen, ideal für die Entwicklung von Methoden zur Behandlung zeitlicher Abhängigkeiten.
- **[Web Tables for Long-Tail Entity Extraction](http://webdatacommons.org/T4LTE/)**: Ein Goldstandard-Datensatz zur Evaluierung der Extraktion von Long-Tail-Entitäten aus Web-Tabellen, motiviert durch die Anreicherung von Wissensdatenbanken mit unbekannten Entitäten.

### Code und Projekte

Zugängliche Implementierungen zur Reproduktion der Forschungsergebnisse.

- **[Extracting Long Tail Entities from Web Tables for Augmenting Cross-Domain Knowledge Bases](http://data.dws.informatik.uni-mannheim.de/expansion/LTEE/)**: Code und Anweisungen zur Reproduktion der Extraktion von Long-Tail-Entitäten aus Web-Tabellen unter Nutzung von Weak Supervision.
- **[Time-Aware Fusion for Web Table Data](http://data.dws.informatik.uni-mannheim.de/expansion/time-aware-fusion/)**: Code und Anweisungen zur Reproduktion der Fusion zeitabhängiger Daten aus Web-Tabellen.
