## Forschungsschwerpunkte (Research)

Christian Bizer forscht an Methoden zur Integration von Daten aus großen Mengen unterschiedlicher Datenquellen im Kontext des offenen Webs und von Unternehmens-Data-Lakes.

**Kerninteressen:**

- Entity Matching (Entitätsextraktion)
- Schema Matching
- Table Annotation (Tabellenanmerkung)
- Information Extraction
- Data Discovery

**Aktueller Fokus:**
Die aktuelle Forschung konzentriert sich auf die Nutzung von **Large Language Models (LLMs)** und LLM-basierten Agenten für Datenintegrationsaufgaben.

**Institutionelle Zugehörigkeit:**
Prof. Dr. Bizer ist Professor an der Universität Mannheim und leitet die Fokusgruppe [Web-based Systems](https://www.uni-mannheim.de/dws/research/focus-groups/web-based-systems-prof-bizer/) innerhalb der [Data and Web Science Group](https://www.uni-mannheim.de/dws/).

**Wichtige Projekte und Initiativen:**

- **DBpedia:** Co-Gründung des Projekts, das einen umfassenden Wissensgraphen aus Wikipedia ableitet.
- **WebDataCommons:** Initiierung des Projekts zur Überwachung der Adaption von Standards wie schema.org, JSON-LD, Microdata und Microformats im Web durch Analyse großer Web-Crawls.

**Open Source Projekte:**

- [MatchGPT](https://github.com/wbsg-uni-mannheim/MatchGPT): Entity Matching mittels LLMs.
- [ExtractGPT](https://github.com/wbsg-uni-mannheim/ExtractGPT): Attributwert-Extraktion mittels LLMs.
- [WebMall](https://wbsg-uni-mannheim.github.io/WebMall/): Benchmark für Web-Agenten.
- [PyDI](https://github.com/wbsg-uni-mannheim/PyDI): Python Data Integration Framework.
- Weitere Projekte finden Sie auf [github.com/wbsg-uni-mannheim](https://github.com/wbsg-uni-mannheim).
