# Sensor Data Collector Application

The Sensor Data Collector is an application designed to record data from common built-in sensors found in wearable devices. It provides comprehensive tools for data acquisition, labeling, visualization, and export, particularly useful in the field of activity recognition.

## Key Features and Functionality

This application supports advanced data collection workflows:

- **Sensor Recording:** Records data from multiple built-in sensors simultaneously. Users can specify the desired sampling rate.
- **Data Labeling:** Allows for precise labeling of the recorded data by specifying the context:
  - Current Activity
  - Posture
  - Location
- **Data Visualization & Export:** Recorded data can be visualized, including live plotting capabilities, and exported in various formats (e.g., SQLite, CSV).
- **Smartwatch Integration:** The system supports the use of smartwatches, which serve two purposes:
  1. **Sensor Recording:** Enables simultaneous sensor recording from different on-body positions (when combined with a smartphone).
  1. **Control Interface:** Provides an additional interface, allowing users to update the current location or activity without needing to physically handle the smartphone, thus ensuring highly accurate data labeling.
