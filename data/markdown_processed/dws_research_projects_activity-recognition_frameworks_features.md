# Sensor Feature Factory

This page provides an overview of the features supported by the [Sensor Feature Factory](https://github.com/sztyler/sensorfeatureextraction) framework. The system covers 10 different features that can be utilized in the context of time- and frequency-domain values.

The framework leverages the [JTransforms](https://sites.google.com/site/piotrwendykier/software/jtransforms) library to transform recorded sensor data from the time-domain into the frequency-domain. This transformation enables the computation of various metrics, such as expended energy.
