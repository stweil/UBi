# Online Random Forest Classifier

This document describes an implementation of an online random forest classifier written in Java. The architecture builds upon the original implementation provided by [Amir Saffari](http://www.ymer.org/amir/software/online-random-forests/), incorporating several enhancements.

## Implementation Details

The classifier implementation is available for use and inspection:

- **Source Code:** Available on [GitHub](link_to_github_source)
- **Binary:** Available on [GitHub](link_to_github_binary)
- **Documentation:** Coming soon

## Technical Specifications and Support

The classifier supports advanced quality measurements and operational features:

- **Quality Measurements:** Information Gain, Gini Index
- **Feature Threshold:** Random, incremental
- **Threading:** Supported (Yes)
- **Export/Import:** Coming soon
- **Java Compatibility:** Requires Java 1.7 or newer (compatible with Android)

A runnable example demonstrating the usage of the classifier can be found here: [Example Usage](https://github.com/sztyler/online-random-forest/blob/master/src/de/unima/classifiers/example/ExampleUsage.java)
