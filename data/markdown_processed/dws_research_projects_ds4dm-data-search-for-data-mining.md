# DS4DM: Data Search for Data Mining

The Data Search for Data Mining (DS4DM) project aims to enhance the data mining platform [Rapidminer](https://rapidminer.com/) by incorporating advanced data search and data integration functionalities.

## Project Overview and Goal

Analysts often face the challenge of knowing that necessary data exists on the Web or within a corporate intranet, but lacking the means to locate it. The primary goal of the DS4DM project is to solve this by extending the data mining platform with capabilities that allow analysts to:

1. Find relevant data within potentially very large data corpora.
1. Semi-automatically integrate the discovered data with existing local datasets.

## Expected Outcomes and Functionalities

The project is expected to deliver several key components:

- **Data Search Engine:** Providing multiple methods for data discovery:
  - Keyword-based data search methods
  - Correspondence-based data search methods
  - Correlation-based data search methods
- **Interactive Data Integration Environment:** A platform for merging disparate data sources.
- **Indexing Components:** Tools designed for indexing data sourced from both intranet and Web locations.

## Project Details

- **Duration:** 2015–2018
- **Funding:** The project was funded by the German [Federal Ministry of Education and Research](https://www.bmbf.de/EN/Home/home_node.html) (BMBF) under the [KMU-innovativ](https://www.bmbf.de/DE/Forschung/Gesellschaft/ZukunftDerArbeit/KmuInnovativ/kmuinnovativ_node.html) scheme, with a funding amount of 400k €.
