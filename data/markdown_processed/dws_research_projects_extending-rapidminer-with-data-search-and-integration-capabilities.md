# Erweiterung von RapidMiner mit Daten-Such- und Integrationsfähigkeiten

**Projektteam:** Anna Lisa Gentile, Sabrina Kirstein, [Heiko Paulheim](https://www.uni-mannheim.de/dws/people/professors/prof-dr-heiko-paulheim/) und [Christian Bizer](https://www.uni-mannheim.de/dws/people/professors/prof-dr-christian-bizer/)

## Problemstellung

Datenanalysten stehen zunehmend vor der Herausforderung, dass benötigte Daten für ein Data-Mining-Projekt zwar im Web oder im Intranet einer Organisation existieren, aber nicht auffindbar sind. Bestehende Data-Mining-Tools bieten zwar leistungsstarke Methoden, unterstützen Analysten jedoch kaum beim Suchen geeigneter Daten oder beim Integrieren von Daten aus multiplen Quellen.

## Lösung: RapidMiner Extension

Das Projekt demonstriert eine Erweiterung des populären Data-Mining-Frameworks [RapidMiner](https://rapidminer.com/). Diese Erweiterung ermöglicht es Analysten, relevante Datensätze zu suchen und die gefundenen Daten mit bereits vorhandenen Daten zu integrieren.

**Kernfunktionen:**

- **Daten-Such- und Integrations-Framework:** Es wird ein umfassendes Framework vorgeschlagen, das den gesamten Prozess abdeckt.
- **Iterative Erweiterung:** Speziell wird die iterative Erweiterung von Tabellendaten mit zusätzlichen Attributen unterstützt.
- **Implementierung:** Es wurde eine initiale Open-Source-Implementierung des Frameworks als [RapidMiner](https://rapidminer.com/) Extension entwickelt.

**Hintergrund:**
Die RapidMiner Extension wird im Rahmen des BMBF-geförderten Forschungsprojekts [DS4DM](https://www.uni-mannheim.de/dws/research/projects/ds4dm-data-search-for-data-mining/) entwickelt.

## Ergebnisse und Anerkennung

Die Demonstration des Konzepts wurde auf der **13th European Semantic Web Conference (ESWC2016)** präsentiert und erhielt den Preis für die beste Demonstration.
