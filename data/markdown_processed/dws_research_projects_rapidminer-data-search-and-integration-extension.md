# RapidMiner Data Search and Integration Extension

The **RapidMiner Data Search and Integration Extension** is an add-on designed for the open-source data mining software [RapidMiner](http://rapid-i.com/content/view/181/190/).

## Functionality and Purpose

This extension is specifically aimed at supporting the iterative extension of data tables. It assists the user by providing capabilities to find appropriate records necessary for the data mining process.

## Project History

A first demonstration of this extension was proposed at the [ESWC2016](https://www.uni-mannheim.de/dws/research/projects/extending-rapidminer-with-data-search-and-integration-capabilities/) conference.
