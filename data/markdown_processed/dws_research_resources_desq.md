# DESQ: System for Frequent Sequence Mining

DESQ is a general-purpose system designed for frequent sequence mining. It features a simple and intuitive pattern expression language to express various pattern mining tasks and provides efficient algorithms for mining.

The following publications detail the research and development surrounding DESQ:

DESQ is an open-source system. The source code is available on [GitHub](https://github.com/rgemulla/desq).
