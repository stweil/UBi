# Seminar: Machine Learning at Scale (SM445/CS 707) HWS 2025

This seminar focuses on **Machine Learning at Scale**. The core theme addresses the challenges and techniques required for modern ML applications involving:

- Large training datasets and compute requirements.
- Large models and high inference costs.
- Large context windows and vector database retrieval.
- Low-latency, high-throughput inference.
- Deployment on edge devices.

We will explore techniques that enable scalability, including parallel processing and various cost-reduction approaches.

Im Laufe des Seminars werden die Teilnehmenden folgende Fähigkeiten erwerben:

- Wissenschaftliche Literatur lesen, verstehen und erforschen.

- Zwei Präsentationen zu ihrem Thema halten (3 Minuten Blitzpräsentation, 15 Minuten Abschlusspräsentation).
- Eine wissenschaftliche Diskussion zu einem Kommilitonen-Thema moderieren.

## 📚 Themengebiete und Forschungsfokus

Die Teilnehmenden erhalten ein breiteres Themengebiet in einem aktiven Forschungsfeld von Machine Learning, basierend auf ihren Präferenzen. Die Arbeit gliedert sich in zwei Teile:

1. **Überblick (1/4):** Eine kurze, prägnante Übersicht über das gesamte Themengebiet (z.B. basierend auf einem Buchkapitel oder Survey Paper). Hierbei geht es um einen Überblick über Ziele, Herausforderungen und Relevanz.
1. **Vertiefung (3/4):** Eine detaillierte Präsentation zu einem selbstgewählten Thema innerhalb des breiteren Feldes (z.B. basierend auf einem aktuellen oder einflussreichen Forschungsartikel). Hierbei wird das konkrete Problem, die Lösung/der Beitrag und eigene Gedanken diskutiert.

**Mögliche Themengebiete:**

- Parallel Training
- Parallel Inference
- Data Management
- Lifecycle Management
- Cost-Savings (Quantisierung, Model Distillation)
- Vector Databases
- Systems for Machine Learning
- Sampling
- Federated Learning
- Mixture of Experts (MoE)
