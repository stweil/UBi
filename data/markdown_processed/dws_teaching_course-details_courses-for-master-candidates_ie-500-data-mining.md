# Data Mining (FSS 2026)

This course provides an introduction to advanced data analysis techniques, serving as a foundation for analyzing business data and providing input for decision support systems.

**Topics Covered:**

- The Data Mining Process
- Data Representation and Preprocessing
- Classification
- Regression
- Clustering
- Association Analysis

**Course Structure:**
The course combines lectures with accompanying practical exercises and culminates in student team projects.

- **Exercises:** Participants gain initial expertise by applying state-of-the-art data mining libraries to realistic datasets.
- **Team Projects:** In the final third of the term, groups undertake sophisticated data mining projects of their choice, presenting their findings via a written report and an oral presentation.
