# Information Retrieval and Web Search (IE663 + IE691)

Given the vastness and richness of the Web, users require high-performing, scalable, and efficient methods to access its information wealth and satisfy their information needs. Consequently, the ability to search and effectively retrieve relevant pieces of information from large text collections is a crucial task for nearly all Web applications.

In this Master's course, we explore a variety of basic and advanced techniques for text-based information retrieval and Web search. The coursework includes exercises, culminating in a final exam (IE 663). Homework assignments are designed to introduce students to the problems covered in the final exam.

### Related Course: IR Project (IE 691)

This course is related to the IR project course (IE 691), where students are expected to successfully complete a team project in groups of 4–5 people. The projects focus on various IR problems covered in class. Project deliverables include both software (i.e., code and documentation) and a short report explaining the work performed and its evaluation.

### Prerequisites

Students should have fundamental knowledge in:

- Linear algebra
- Probability theory
- Algorithms and data structures
- Programming skills (Java or Python are recommended for the IR Project, IE 691)
