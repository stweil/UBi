# Web Data Integration (HWS2025)

Data integration is a core challenge in many IT projects. It is estimated that data scientists spend about 80% of their time on data integration and preparation. In an enterprise context, data integration techniques are applied whenever data from separate sources must be combined for new applications or analytical purposes. In the context of the Web, data integration is foundational for leveraging the growing number of publicly-accessible data sources, enabling applications such as product comparison portals, job search platforms, and finance/real-estate data analysis.

In this course, students will learn and experiment with techniques for integrating and cleansing data from large sets of heterogeneous data sources.

### Course Topics Covered

The curriculum covers the following key areas:

- Heterogeneity and Distributedness
- The Data Integration Process
- Structured Data on the Web
- Data Exchange Formats
- Data Quality and Data Profiling
- Schema Mapping and Data Translation
- Identity Resolution
- Data Fusion

### Course Structure and Credits (ECTS)

The course is divided into two components: a lecture and accompanying practical projects.

- **Lecture (IE670):** Covers the theory and methods of web data integration and concludes with a written exam (3 ECTS).
- **Projects (IE683):** Students gain practical experience by applying web data integration methods to a real-world use case of their choice. Work is done in teams and reported via a written report and an oral presentation (3 ECTS).

> **Recommendation:** While the lecture and project can be attended in separate years, it is highly recommended to attend both in the same semester as the schedules are aligned.

### Prerequisites and Tools

- **Programming Skills:** Proficiency in Python and experience with the `pandas` and `scikit-learn` libraries are required for the exercises and projects.
- **Tools:**
  - [Altova MapForce – Graphical Data Mapping, Conversion, and Integration Tool](https://www.altova.com/mapforce.html)
  - [PyDI – Python Data Integration Framework](https://github.com/wbsg-uni-mannheim/PyDI)
