# IE 675b: Machine Learning (HWS 2025)

This document outlines the structure, content, and prerequisites for the course IE 675b: Machine Learning.

## 📚 Kursübersicht und Organisation

- **Kursart:** Vorlesung, Übungen, Aufgaben (9 ECTS Punkte)
- **Dozent:** [Prof. Dr. Rainer Gemulla](https://www.uni-mannheim.de/dws/people/professors/prof-dr-rainer-gemulla/)
- **Tutor:** [Julie Naegelen](https://www.uni-mannheim.de/dws/people/researchers/phd-students/julie-naegelen/)
- **Voraussetzungen:** IE 500 Data Mining I (empfohlen / parallel) sowie Kenntnisse in Wahrscheinlichkeitstheorie und Statistik.
- **Anmeldung:** Im Portal 2 einschreiben.

**Ablauf:**
Die Vorlesung (2 Sitzungen pro Woche) und die Tutorien (1 Sitzung pro Woche) finden Präsenz statt und beginnen in der ersten Woche. Details werden in der **Kickoff-Vorlesung (Dienstag, 2. Sep, 10:15 Uhr)** besprochen.

## 🧠 Kursinhalt (Content)

Machine Learning beschäftigt sich mit dem Aufbau von Computersystemen, die mit Erfahrung besser werden, sowie mit dem Studium von Lernprozessen, einschließlich der Entwicklung von Algorithmen, die Vorhersagen treffen oder Wissen aus Daten extrahieren können. Das Ziel dieses Moduls ist eine Einführung in das Feld des Machine Learning, einschließlich der Untersuchung von Algorithmen, zugrundeliegenden Konzepten und theoretischen Prinzipien.

**Themenbereiche:**

- Grundlagen des Machine Learning
- Training, Inferenz, Entscheidungsfindung
- Generative Modelle (z.B. Beta-binomial, Naive Bayes, PPCA)
- Diskriminative Modelle (z.B. logistische Regression, SVM, GPR)
- Latente Variablen Modelle (z.B. SVD, LLM, GMM)
- Der EM-Algorithmus
- Kernel-Methoden
- Hyperparameter-Optimierung

*Hinweis:* Deep Learning und fortgeschrittenere Themen werden im Folgekurs „IE 678 Deep Learning“ (und anderen) behandelt.
