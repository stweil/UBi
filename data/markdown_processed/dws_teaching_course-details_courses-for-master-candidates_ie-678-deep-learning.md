# IE 678: Deep Learning (FSS 2026)

Dieser Kurs bietet eine Vertiefung im Bereich Deep Learning und baut auf den Grundlagen des Machine Learning auf.

## 📚 Kursübersicht und Organisation

- **Kursbezeichnung:** IE 678: Deep Learning
- **ECTS-Punkte:** 6 ECTS
- **Format:** Vorlesung (Präsenz), Übungen, Aufgaben
- **Voraussetzung:** IE 675b Machine Learning oder Äquivalent
- **Dozenten:**
  - [Prof. Dr.-Ing. Margret Keuper](https://www.uni-mannheim.de/dws/people/professors/prof-dr-ing-margret-keuper/)
  - [Simon Forbat](https://www.uni-mannheim.de/dws/people/researchers/phd-students/simon-forbat/)
- **Ablauf:** Die Vorlesung (Dienstag) und die Übung (Mittwoch) beginnen in der ersten Woche.
- **Materialien:** Vorlesungsfolien, Übungen und Aufgaben sind in [ILIAS](https://ilias.uni-mannheim.de/goto.php/crs/1719793) verfügbar (Zugang über Portal² erforderlich).

## 🧠 Inhaltlicher Fokus

Der Kurs erweitert das Verständnis von Machine Learning, indem er sich auf Deep Learning konzentriert. Es werden grundlegende und fortgeschrittene Architekturen, Trainingsmethoden und Hyperparameter-Optimierungstechniken behandelt, ergänzt durch ausgewählte Anwendungsfälle.

**Geplante Themenbereiche:**

- Feedforward Neural Networks
- Backpropagation und Parameteroptimierung
- Machine Learning Systeme
- Trainingsmethoden für Deep Learning Modelle
- Recurrent Neural Networks (RNNs)
- Convolutional Neural Networks (CNNs)
- Attention und Transformers
- Deep Learning für Graphen
- Deep Generative Modelling
