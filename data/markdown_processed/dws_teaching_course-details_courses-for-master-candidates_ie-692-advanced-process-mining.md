# IE 692: Advanced Process Mining (FSS 2024)

Process mining is an emerging branch of data science focused on deriving qualitative and quantitative insights into the execution of organizational processes by analyzing recorded event sequences. This course provides comprehensive coverage of the formal foundations, algorithms, and advanced techniques within the field.

## Course Content and Topics

The curriculum covers several core aspects of process mining:

- **Process Discovery:** Deriving a process model directly from recorded event data.
- **Conformance Checking:** Identifying deviations between actual event data and established process models.
- **Process Enhancement:** Augmenting process models by incorporating information from temporal, organizational, and data perspectives.
- **Predictive Monitoring:** Making predictions regarding ongoing process instances.
- **Data Preprocessing:** Techniques for preprocessing, abstracting, and clustering event data to improve analytical results.

The course utilizes fundamental algorithms alongside advanced, state-of-the-art techniques. Learning is reinforced through practical exercises (pen-and-paper and implementation using open-source tools) and culminates in a group project involving the implementation or evaluation of a process mining technique.

## Learning Objectives (Goals)

Upon successful completion of this course, students will be able to:

- Understand the fundamental importance and potential scope of process mining.
- Apply both fundamental and advanced techniques for core process mining tasks.
- Analyze real-world data effectively using open-source process mining tools.
