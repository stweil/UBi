## 📚 Past Projects

### Web2Table: Using LLMs to Generate Tables about Arbitrary Topics from the Web (HWS2024)

This project addresses the need to structure scattered online information into user-friendly tables. It explores how effectively LLMs can automate the table creation process by combining information from multiple sources for analysis or recommendations.
**Supervisors:**

- [Alexander Brinkmann](https://www.uni-mannheim.de/dws/people/alumni/alexander-brinkmann/)
- [Christian Bizer](https://www.uni-mannheim.de/dws/people/alumni/alexander-brinkmann/)

### Benchmarking Function-Calling Enabled LLMs (HWS2023)

This project focuses on building a benchmark to test the function-calling ability of Large Language Models (LLMs). The goal is to investigate how function descriptions and different query formulations affect the performance of models like ChatGPT and GPT-4, addressing issues like advanced reasoning and hallucination.
**Supervisors:**

- [Keti Korini](https://www.uni-mannheim.de/dws/people/researchers/phd-students/keti-korini/)
- [Christian Bizer](https://www.uni-mannheim.de/dws/people/professors/prof-dr-christian-bizer/)
  **Resources:**
- [Kick-off Slides (PDF, 2 MB)](https://www.uni-mannheim.de/media/Einrichtungen/dws/Files_Teaching/Team_Projects/TableAnnotationUsingDeepLearning/TeamProject_HWS2023_KickOff_Slides.pdf)
- [Project Report](https://data.dws.informatik.uni-mannheim.de/Web-based-Systems-Group/StudentProjects/2024/Benchmarking%20Function-Calling%20Enabled%20LLMs/)

### Table Annotation using Deep Learning (HWS2022)

The project investigates using Transformer-based deep learning methods for table annotation—the process of annotating tables with terms from a knowledge graph or database schema. Participants experiment with various pre-training, fine-tuning, and data augmentation techniques using Python and Huggingface.
**Supervisors:**

- [Keti Korini](https://www.uni-mannheim.de/dws/people/researchers/phd-students/keti-korini/)
- [Christian Bizer](https://www.uni-mannheim.de/dws/people/professors/prof-dr-christian-bizer/)

### Active and Online Learning – Your Personal Assistant for Lifestyle Improvement (2017/2018)

This project focuses on using inertial sensors (Accelerometer, Gyroscope) to recognize physical activities (e.g., climbing stairs, walking). The goal is an Android app that learns and updates a classification model online while interacting with the user regarding uncertain results.
**Supervisors:**

### Topic Monitoring in the Pharmaceutical Industry

This project uses social media (Facebook, Twitter) to analyze public perception regarding specific companies, addressing questions about trending topics, recurring themes, and geographical differences.

### Knowledge Extraction from WikiFarms

The aim is to fill the "long tail" of large public knowledge graphs (like DBpedia) by leveraging detailed information from smaller, specialized Wikis (like those found at WikiFarms). The project investigates data quality and integration challenges.
**Supervisors:**

- [Heiko Paulheim](https://www.uni-mannheim.de/dws/people/professors/prof-dr-heiko-paulheim/)
- [Sven Hertling](https://www.uni-mannheim.de/dws/people/professors/dr-sven-hertling/)

### Exploring the Future Warehouse

This project develops a system to recognize and optimize worker activities in logistics using video and sensor data from smart devices (e.g., data glasses). The output is a mobile application to assist warehouse workers.
**Supervisors:**

### FitFor4: Semantics-based Integration of Cyber-Physical Systems in the Industrial Internet

This master project tackles Industry 4.0 challenges by constructing an Industry 4.0 compliant infrastructure based on semantic interface descriptions, aiming to solve integration and compatibility issues in long-lifecycle production machines.
