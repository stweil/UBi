# Information for Prospective Students: CDSS Doctoral Program

This section provides prospective students with an overview of various topics related to the CDSS doctoral program.

- **For Active Students:** Doctoral students already enrolled in the program can find more detailed information [here](https://www.uni-mannheim.de/gess/for-active-students/).
- **CDSS Info Booklet:** Additional comprehensive information is available in the CDSS Info Booklet (PDF, 444 kB). This booklet elaborates on the GESS in general, the CDSS program structure, information for international students, studying and living in Mannheim, and many other topics.
- **Questions:** For any further questions, please contact the CDSS Center Manager via email.
