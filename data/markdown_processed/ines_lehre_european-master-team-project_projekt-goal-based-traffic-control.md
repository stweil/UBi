# Goal-Based Traffic Control System

[Goal Based Traffic Control](https://www.uni-mannheim.de/ines/lehre/european-master-team-project/projekt-goal-based-traffic-control/)

## Problem Description

Urban centers frequently suffer from significant traffic congestion, which leads to increased noise and air pollution, particularly during rush hours. Current traffic light systems often rely on static control patterns, failing to adapt to dynamically changing traffic flows.

## Project Goal and Approach

The objective of this Master Team Project is to develop an **adaptive traffic control system** that manages traffic lights based on a **Goal Recognition** approach.

Goal Recognition involves predicting or recognizing an observed agent's goal by analyzing a domain model and the sequence of actions the agent has already executed. By controlling traffic lights based on the recognized destinations of observed traffic participants, the system aims to significantly reduce congestion.

## Methodology and Implementation

The project involves developing a traffic control system within a simulated environment using the **SUMO traffic simulator**.

Participants will gain hands-on experience with:

- The SUMO traffic simulation tool.
- Advanced Goal Recognition approaches derived from concepts in classical planning.

## Participants

The project is a collaborative effort between:

- Four students with a strong interest in Artificial Intelligence, specifically classical planning.
- Four software engineering students from Cluj-Napoca.
