# Wie formatiere ich einen USB-Stick mit FAT32?

Diese Anleitung beschreibt, wie Sie einen USB-Stick mithilfe von Windows Explorer auf das Dateisystem FAT32 formatieren, damit er für die Verwendung an den Ricoh Kopierern (z.B. für Scan-to-USB oder Ausdrucken von Dateien) geeignet ist.

### ⚠️ Wichtige Hinweise vorab

- **Datenverlust:** Der gesamte Inhalt des USB-Sticks wird im Formatierungsprozess gelöscht. Stellen Sie sicher, dass keine Daten mehr auf dem Stick vorhanden sind, die Sie benötigen.
- **Korrekte Auswahl:** Vergewissern Sie sich unbedingt, dass Sie das korrekte Laufwerk auswählen, um Datenverlust oder Systemschäden zu vermeiden.

### Schritt-für-Schritt-Anleitung

1. **Anschließen:** Schließen Sie den USB-Stick an Ihren Windows-PC an und warten Sie, bis das Gerät vom System erkannt wurde.
1. **Explorer öffnen:** Öffnen Sie den Windows-Explorer (Windows-Taste + E). Suchen Sie den USB-Stick in der linken Navigationsleiste unter „Dieser PC“ oder im Hauptfenster unter „Geräte und Laufwerke“.
1. **Formatieren starten:** Klicken Sie mit der rechten Maustaste auf das Symbol des USB-Sticks und wählen Sie im Kontextmenü die Option **„Formatieren“**.
1. **Einstellungen wählen:** Im erscheinenden Fenster konfigurieren Sie folgende Einstellungen:
   - **Dateisystem:** Wählen Sie **„FAT32“**.
   - **Volumebezeichnung:** Geben Sie einen Namen für den Stick ein (z.B. „MFP-Stick“).
   - **Schnellformatierung:** Stellen Sie sicher, dass das Häkchen bei „Schnellformatierung“ gesetzt ist.
1. **Ausführen:** Klicken Sie anschließend auf **„Starten“**.
1. **Bestätigung:** Bestätigen Sie die Warnmeldung, dass alle Daten gelöscht werden, mit **„OK“**, um die Formatierung mit FAT32 durchzuführen.
1. **Abmelden:** Melden Sie den USB-Stick anschließend wie gewohnt vom System ab („sicheres Entfernen“).

Ihr USB-Stick ist nun für die Verwendung an den Ricoh-Kopierern vorbereitet.
