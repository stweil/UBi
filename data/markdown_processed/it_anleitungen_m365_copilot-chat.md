# Microsoft Copilot Chat

Microsoft Copilot Chat bietet einen sicheren KI-Chat mit verschiedenen Funktionen, darunter:

- Zugriff auf das Internet
- Zusammenfassen und Generieren von Texten
- Generieren von Bildern
- Analyse einfacher Daten

## Copilot Chat vs. M365 Copilot

Copilot Chat ist **nicht identisch** mit M365 Copilot. Die beiden unterscheiden sich im Funktionsumfang und in der Anbindung. Weitere Details zu den Unterschieden finden Sie auf den [Seiten von Microsoft](https://learn.microsoft.com/en-us/copilot/overview#differences-between-copilot-chat-and-microsoft-365-).

## Wie nutze ich den Copilot Chat?

Sie können den Copilot Chat über verschiedene Kanäle nutzen:

- **Webbrowser:** [https://m365.cloud.microsoft/chat/](https://m365.cloud.microsoft/chat/)
- **Microsoft 365 Copilot Desktop App:** Diese App können Sie unter den [Microsoft Apps](https://m365.cloud.microsoft/apps) oben rechts installieren. Nach dem Öffnen der Anwendung sehen Sie direkt den Copilot Chat auf der Startseite.
- **In Office-Anwendungen (z.B. Word):** Innerhalb Ihrer Anwendung finden Sie das Icon von Copilot Chat oben rechts.

Um den Chat zu starten, geben Sie Ihren Prompt ein.

Für weitere Informationen zu Copilot Chat konsultieren Sie bitte die offiziellen [Microsoft Anleitungen](https://learn.microsoft.com/de-de/copilot/overview). Häufig gestellte Fragen finden Sie im [Copilot Chat FAQ von Microsoft](https://learn.microsoft.com/de-de/copilot/faq).
