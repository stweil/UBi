# Wie schreibe ich eine E-Mail aus einem Funktionspostfach im Webmailer OWA?

Um eine E-Mail aus einem Funktionspostfach im Webmailer OWA zu verfassen, folgen Sie bitte diesen Schritten:

1. **Outlook Web App (OWA) aufrufen:**
   Rufen Sie die Outlook Web App unter [https://exchange.uni-mannheim.de](https://exchange.uni-mannheim.de/) auf.

1. **Anmelden:**
   Geben Sie Ihre Uni-ID unter „Uni-ID“ und Ihr zugehöriges Passwort unter „Kennwort“ ein. Klicken Sie anschließend auf „Anmelden“.

1. **Weiteres Postfach öffnen:**
   Klicken Sie auf Ihr Bild/Ihre Initialen rechts oben (1) und wählen Sie „Weiteres Postfach öffnen“ (2).

1. **Funktionspostfach auswählen:**
   Geben Sie im Fenster „Weiteres Postfach öffnen“ den Namen des Funktionspostfachs ein und klicken Sie auf „Öffnen“. Das Funktionspostfach öffnet sich in einem neuen Tab.
   *Hinweis:* Falls eine Warnmeldung Ihres Browsers erscheint, erlauben Sie bitte das Öffnen von Tabs für [exchange.uni-mannheim.de](https://exchange.uni-mannheim.de/).

1. **E-Mail erstellen:**
   Klicken Sie auf **Neu → E-Mail**, um eine E-Mail aus dem Funktionspostfach im Webmailer OWA zu schreiben. Als Absender\*innenadresse wird automatisch die E-Mail-Adresse des Funktionspostfachs verwendet.

1. **Verlassen des Funktionspostfachs:**
   Zum Beenden der Arbeit schließen Sie bitte einfach das Tab des Funktionspostfachs. Sie sehen danach wieder Ihr eigenes Postfach im Webmailer.
