# Login in die Webmail-Anwendung (OWA)

Diese Anleitung zeigt Ihnen, wie Sie Ihr Exchange-Postfach online über die Webmail-Anwendung OWA (Outlook Web App) aufrufen können.

### Schritte zum Zugriff

1. Rufen Sie die [Outlook Web App (OWA)](https://exchange.uni-mannheim.de/) auf.
1. Geben Sie die folgenden Informationen ein:
   - **Benutzername:** Ihre Uni-ID
   - **Kennwort:** Das zu Ihrer Uni-ID gehörende Passwort
1. Klicken Sie anschließend auf „Anmelden“.

Nach diesen Schritten gelangen Sie direkt zu Ihrem Postfach.
