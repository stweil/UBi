# Wechsel auf Windows 11

Am 14. Oktober 2025 endet der Support für Windows 10, weshalb ein Wechsel auf Windows 11 notwendig ist. Bitte sichern Sie Ihre Daten, bevor Sie mit dem Upgrade beginnen.

**Hinweis für die Verwaltung:** Kolleg\*innen in der Verwaltung nutzen eine spezielle Version von Windows 10. Diese ist nicht vom Supportende betroffen oder der Wechsel auf Windows 11 wurde bereits durchgeführt. Sie erhalten hierzu gesonderte Informationen von Ihrem Support.

## 1. Warum sollte ich wechseln?

Ein Verbleib bei Windows 10 über das Support-Ende hinaus stellt ein unkalkulierbares Risiko für die Sicherheit Ihrer Geräte dar, da keine Sicherheitsupdates mehr bereitgestellt werden. Zudem ist ein zusätzliches Support-Ende für bestimmte Programme (wie beispielsweise Microsoft Teams) absehbar, was zu Kompatibilitätsproblemen führen kann.

## 2. Überprüfung der Windows-Version

Sie können selbstständig prüfen, welche Windows-Version Sie aktuell nutzen:

1. Klicken Sie mit der rechten Maustaste auf das Windows-Start-Icon.
1. Wählen Sie **System**.
1. Unter **Windows-Spezifikation** sehen Sie die aktuell genutzte Version.

Falls hier bereits Windows 11 angezeigt wird, ist kein Handeln erforderlich. Ansonsten wird ein Wechsel empfohlen.

## 3. Kompatibilität Ihres Geräts prüfen

Bitte prüfen Sie zunächst selbstständig, ob Ihr Gerät die Systemanforderungen für Windows 11 erfüllt:

- [Hier](https://support.microsoft.com/de-de/windows/%C3%BCberpr%C3%BCfen-ob-ihr-ger%C3%A4t-die-windows-11-systemanforderungen-nach-dem-%C3%A4ndern-der-ger%C3%A4tehardware-erf%C3%BCllt-f3bc0aeb-6884-41a1-ab57-88258df6812b)

Ist Ihr Gerät nicht geeignet, empfiehlt sich ein Wechsel auf ein neues Gerät. Informationen zur Beschaffung finden Sie [hier](https://intranet.uni-mannheim.de/organisation/stabs-und-servicestellen/beschaffung/bezug-bestimmter-waren-und-leistungen/informations-und-kommunikationstechnik/).

## 4. Daten­sicherung (Backup)

Standardmäßig bleiben bei einem **Upgrade auf Windows 11** alle Einstellungen und Inhalte erhalten. Dennoch wird dringend empfohlen, vorab eine vollständige Datensicherung durchzuführen.

## 5. Anleitung zum Upgrade auf Windows 11

Der bevorzugte Weg ist ein Systemupgrade, welches in der Regel automatisch vorgeschlagen wird. Sollte dies nicht der Fall sein, kann das Upgrade manuell ausgelöst werden.

### A. Systemupgrade durchführen (Empfohlen)

**Wenn das Upgrade aktiv vorgeschlagen wird:**

1. Klicken Sie auf **Abrufen** und fahren Sie mit **Schritt 2** fort.

**Wenn das Upgrade manuell ausgelöst werden muss:**

1. Öffnen Sie die **Einstellungen** (Rechtsklick auf Start-Symbol oder Shortcut: `Windows-Taste + I`).
1. Navigieren Sie zu **Update & Sicherheit** und dann zum Reiter **Windows Updates**.
1. **Schritt 2:** Suchen Sie das Banner, das Windows 11 anbietet. Klicken Sie darauf und wählen Sie **Herunterladen und Installieren**.
1. **Schritt 3:** Akzeptieren Sie die Software-Lizenzbedingungen und klicken Sie auf **Akzeptieren und installieren**.
1. **Schritt 4:** Nach dem Herunterladen und der Installation (siehe Abbildungen 4 und 5) führen Sie einen Neustart durch, um das Upgrade abzuschließen.

### B. Neuinstallation durchführen (Alternative)

Eine Alternative ist die Neuinstallation von Windows 11. **Achtung:** Bei dieser Methode gehen alle Einstellungen verloren. Programme und Daten müssen nach der Neuinstallation vollständig neu aufgespielt werden. Bitte kontaktieren Sie hierfür direkt Ihren zuständigen IT-Support.
