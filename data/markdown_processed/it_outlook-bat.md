# Outlook Autodiscovery: Verbindung Ihres Exchange-Postfachs mit Outlook

Diese Anleitung beschreibt die einmalige Einrichtung der Verbindung Ihres Outlook-Clients mit einem Exchange-Postfach, indem die notwendigen Registry-Schlüssel (RegKey) gesetzt werden.

**Voraussetzung:**

- Outlook 365 muss bereits auf Ihrem PC/Laptop installiert sein.

## Schritt-für-Schritt-Anleitung zur Einrichtung

Beim allerersten Verbinden von Outlook mit dem Exchange-Server führen Sie bitte die folgenden Schritte einmalig durch:

1. **Download der Datei:** Laden Sie die Datei „Outlook Autodiscovery RegKey setzen.bat“ herunter:
   [Download Outlook Autodiscovery RegKey.bat](https://www.uni-mannheim.de/media/Einrichtungen/it/Anleitungen/Exchange/Outlook_Autodiscovery_RegKey/Outlook_Autodiscovery_RegKey_setzen.bat)

1. **Ausführen der Datei:** Führen Sie die heruntergeladene Datei „Outlook Autodiscovery RegKey setzen.bat“ durch einen Doppelklick aus.

**Wichtige Hinweise während der Ausführung:**

- **Sicherheitswarnungen:** Sollte die Datei von Windows Defender oder einer anderen Antiviren-Software blockiert werden, lassen Sie diese Meldung bitte zu.
- **Konsolenfenster:** Falls sich ein schwarzes Konsolenfenster öffnet, tippen Sie **„j“** in das Fenster ein und bestätigen Sie die Eingabe mit der **Enter-Taste**.

Für eine vollständige und detaillierte Anleitung zur Einbindung von Microsoft Exchange in Windows finden Sie [hier](https://www.uni-mannheim.de/it/anleitungen/microsoft-exchange/einbinden-windows/).
