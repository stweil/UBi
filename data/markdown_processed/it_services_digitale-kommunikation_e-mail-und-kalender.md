# E-Mail-Service und Kalenderverwaltung für Beschäftigte

Die Universität Mannheim stellt allen Beschäftigten und Studierenden einen eigenen E-Mailaccount mit Postfach im **Exchange Mailsystem** zur Verfügung. Über den Webmailer OWA oder Programme wie Outlook können Sie damit E-Mails, Kalender und Kontakte verwalten.

## 📧 Zugriff auf das Exchange-Postfach

Sie haben zwei Hauptmöglichkeiten, auf Ihr Exchange-Postfach zuzugreifen:

### 1. Über den Webmailer OWA (Outlook Web App)

Rufen Sie die Seite [exchange.uni-mannheim.de](https://exchange.uni-mannheim.de) auf. Für den Login benötigen Sie Ihre Uni-ID und das dazugehörige Passwort ([Passwort vergessen?](https://www.uni-mannheim.de/it/anleitungen/passwort/)).

### 2. Über einen E-Mail-Client

In unseren Schritt-für-Schritt-Anleitungen zeigen wir Ihnen, wie Sie Ihre E-Mails, Termine und Adressen auch über Outlook oder andere Programme verwalten können:

- [Anleitung für Windows-PC/ -Laptop (Outlook, Thunderbird oder Windows Mail App)](https://www.uni-mannheim.de/it/anleitungen/microsoft-exchange/einbinden-windows/)
- [Anleitung für MacBook oder iMac (Outlook oder Apple Mail)](https://www.uni-mannheim.de/it/anleitungen/microsoft-exchange/einbinden-macos/)
- [Anleitung für iPhone oder iPad](https://www.uni-mannheim.de/it/anleitungen/microsoft-exchange/einbinden-ios/)
- [Anleitung für Android Smartphone oder Tablet](https://www.uni-mannheim.de/it/anleitungen/microsoft-exchange/einbinden-android/)
- [Anleitung für Linux-PC/ -Laptop (Thunderbird)](https://www.uni-mannheim.de/it/anleitungen/microsoft-exchange/einbinden-linux/)

## ✨ Funktionen des E-Mail-Services

Das stabile Mailsystem mit 6 GB Speicherplatz bietet zahlreiche Vorteile:

- **Sicherheit:** Umfassender SPAM-Schutz.
- **Datensicherung:** Tägliche lokale Sicherung der Daten im Netz der Universität Mannheim.
- **Wiederherstellung:** Möglichkeit zur Datenwiederherstellung bis zu zwei Wochen nach Löschen ([Anleitung](https://www.uni-mannheim.de/it/anleitungen/microsoft-exchange/wiederherstellen-geloeschter-mails/)).
- **Organisation:** Einfache Verwaltung von Regeln zur Organisation eingehender Nachrichten.
- **Kontakte:** Globale Adressbücher für schnelles Auffinden von Mailadressen.
- **Kalender:** Freigabe von Kalendern inklusive individueller Vergabe von Zugriffs- und Bearbeitungsrechten.
- **Terminplanung:** Komfortable Terminplanungsassistenten, die die Verfügbarkeit der Teilnehmenden anzeigen (unabhängig von der Kalenderfreigabe).
- **Abwesenheitsnachrichten:** Aktivierung automatischer Antworten (Abwesenheitsnachrichten) für definierte Zeiträume.
- **Massenkommunikation:** Erstellung von Mailinglisten für den Versand von Serien- bzw. Massenmails über [Mailman](https://www.uni-mannheim.de/it/services/digitale-kommunikation/mailman/).

> **Hinweis zu Weiterleitungen:** Sie können eingehende Nachrichten automatisch auf eine andere universitäre E-Mail-Adresse weiterleiten ([Anleitung Weiterleitung](https://www.uni-mannheim.de/it/anleitungen/microsoft-exchange/weiterleitung-einrichten/)). **Wichtig:** Die Weiterleitung an private Mailkonten oder universitätsexterne Server ist allen Beschäftigten nicht gestattet.

## ⚙️ Technische Details und Voraussetzungen

### Nutzungsvoraussetzungen

**Rechtliche Vorgaben:**

- Der Nutzer ist selbst verantwortlich für die Freigabe seiner Adressbücher oder Kalender sowie gespeicherte Dateninhalte.
- Bitte beachten Sie die [Benutzungsordnung (PDF, 28 kB)](https://www.uni-mannheim.de/media/Einrichtungen/it/Benutzerordnung_und_wichtige_Dokumente/Benutzungsordnung_Informationssysteme_Universitaet_Mannheim.pdf).

**Technische Vorgaben:**

- Alle gängigen Webbrowser werden unterstützt.
- Für die volle Funktionalität wird die Nutzung über die Webanwendung oder den E-Mail-Client Outlook empfohlen.
- Sie benötigen Ihre Uni-ID sowie das zugehörige Passwort.

### IMAP/SMTP Einstellungen für externe Clients

Wir empfehlen die Verwendung des Kontotyps „Exchange“. Falls Sie eine Verbindung über IMAP herstellen möchten, verwenden Sie folgende Daten:

**IMAP (Posteingangsserver):**
| Protokoll | IMAP |
| :--- | :--- |
| Server | exchange.uni-mannheim.de |
| Port | 993 |
| Sicherheitstyp/Verschlüsselung | SSL/TLS |
| Benutzername | Uni-ID |
| Passwort | Passwort Ihrer Uni-ID |

**SMTP (Postausgangsserver):**
| Server | exchange.uni-mannheim.de |
| :--- | :--- |
| Port | 587 |
| Sicherheitstyp/Verschlüsselung | STARTTLS |
| „Anmeldung/Authentifizierung erforderlich“ | ja |
| Benutzername | Uni-ID |
| Passwort | Passwort Ihrer Uni-ID |
