# Konnektor-Anbindung für das DoSV

Sie können den Konnektor kostenlos herunterladen und innerhalb von 5 Minuten an die Servicestelle des DoSV anbinden.

## Technische Details und Installation

Der Konnektor ist plattformübergreifend verfügbar und läuft auf **Windows, Linux oder Mac** sowie mit **Python ab Version 2.7.9**.

Die Basisanwendung wird automatisiert über folgenden Befehl installiert:

```bash
pip install https://konnektor.uni-mannheim.de/downloads/sestco-0.3.zip
```

Für eine lückenlose technische Dokumentation, die individuelle Anpassungen und die zukünftige Projektpflege erleichtert, finden Sie die \[Sestco Documentation\](Sestco Documentation).
