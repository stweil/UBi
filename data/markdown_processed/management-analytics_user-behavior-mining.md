# User Behavior Mining: Analyse und Vorhersage von Software-Nutzungsverhalten

Die detaillierte Beobachtung des Nutzerverhaltens ist für Softwareunternehmen wie SAP unerlässlich. Nur so kann festgestellt werden, ob das tatsächliche Verhalten der intendierten Nutzung entspricht. Ein Abweichen kann sich negativ auf die Effizienz der ausgeführten Geschäftsprozesse sowie die empfundene Usability der Software auswirken.

**User Behavior Mining (UBM)** verfolgt, wie Nutzer\*innen mit Software interagieren, um Geschäftsobjekte zu bearbeiten. Dies ermöglicht beispielsweise die Beobachtung der Schritte, die zur Bearbeitung von Kundenaufträgen und Rechnungen unternommen wurden.

## Forschungsprojekt und Methodik

Die übergeordnete Vision dieses Forschungsprojekts von Prof. Dr. Jana Rehse in Zusammenarbeit mit SAP Business Process Intelligence (BPI) ist die Verbesserung der Benutzerunterstützung und -erfahrung sowie die Aufdeckung situationsbedingter Automatisierungspotenziale der SAP-Systeme.

Zur Erreichung dieses Ziels werden bestehende Methoden aus dem **Process Mining** auf UBM-Daten adaptiert und weiterentwickelt:

- **Clusteranalyse:** Ein Ansatz zur Identifizierung verschiedener Nutzer\*innengruppen in den Daten, um individuelle Bedürfnisse besser zu unterscheiden und die Software entsprechend anzupassen.
- **Maschinelles Lernen:** Implementierung eines Ansatzes zur Vorhersage von Nutzungsverhalten. Dies soll zukünftig eine Assistenzfunktion ermöglichen, die eine schnellere Navigation innerhalb der Software gewährleistet.

Dank der Menge und hohen Auflösung der Daten ist dabei eine rein datengetriebene Herangehensweise möglich.
