# Introduction to Cognitive Modeling

This workshop, presented during the 2023 Summer School, provides a comprehensive overview of cognitive modeling.

**Instructors:**

- Chris Donkin (LMU Munich)
- Nathan Evans (University of Queensland)

**Course Description:**
Participants will receive an overview of cognitive modeling through a combination of lectures, discussions, and hands-on exercises. The course aims to demonstrate how cognitive modeling can advance psychological theories and will cover the necessary tools to achieve this goal.

Key topics covered include:

- Conceptual issues surrounding cognitive modeling (e.g., differences from statistical modeling and verbal theories).
- The process of moving from a verbal theory to a formal model.
- Technical methods for computational or mathematical cognitive modeling, including:
  - Parameter estimation
  - Model evaluation
  - Model selection (from both frequentist and Bayesian perspectives)

The content will consistently relate these techniques back to the larger goal of advancing theory development and testing, using specific cognitive models (such as evidence-accumulation models) as examples.

**Prerequisites:**
Participants are expected to have:

- Experience using the R programming language.
- Familiarity with basic concepts of Bayesian analysis (e.g., likelihood, prior distribution, posterior distribution).
