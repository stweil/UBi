# Machine Learning Methods for Modeling in Psychology

This workshop, presented by **David Goretzko** (Utrecht University) and **Philipp Sterner** (Ruhr University Bochum, German Center for Mental Health DZPG), introduces the fundamentals of Machine Learning (ML) modeling, with a specific focus on applications within psychological research and assessment.

## Workshop Content Overview

The course provides a comprehensive, hands-on exploration of the entire ML modeling cycle using the R programming language. Participants will cover:

- **Core ML Concepts:** General introduction to key ML concepts.
- **Model Evaluation:** Different resampling strategies to ensure valid performance evaluation of complex modeling pipelines.
- **Algorithms:** Tree-based supervised learning algorithms, presented as state-of-the-art approaches for tabular data.
- **Optimization Techniques:**
  - Regularization, used to prevent overfitting and boost generalizability.
  - Hyperparameter-tuning, methods to optimize ML algorithm performance.
- **Performance Measurement:** Different performance metrics for both classification and regression tasks.
- **Benchmarking:** How to set up rigorous benchmarks for model selection.

## Advanced Topics for Psychologists

The workshop features two critical extensions to standard ML modeling, highly relevant for psychological contexts:

1. **Interpretable Machine Learning (IML):**
   - Addresses the "black-box" problem common with high-accuracy ML algorithms.
   - Provides tools for understanding model decisions, including local explanations, feature importance metrics, and visualizations of marginal effects, making models more understandable to researchers.
1. **Cost-Sensitive Learning (CSL):**
   - Recognizes that classification errors do not carry equal consequences (e.g., in suicide prevention, the cost of a false negative differs greatly from a false positive).
   - CSL provides methods to account for these varying misclassification costs, which is critical for mitigating real-world impact.

## Practical Application and Prerequisites

**Hands-on Experience:**
Participants will apply all discussed concepts and modeling strategies through practical exercises in **R**. These exercises guide users through:

- Setting up key components of a modeling pipeline.
- Evaluating various algorithms in a benchmarking experiment.
- Selecting the most suitable model and interpreting its predictions.
- Implementing practical applications of IML and CSL methods.

**Prerequisite Knowledge:**
Participants should have:

1. Familiarity with **R software** for data analysis.
1. A good understanding of (parametric) **regression modeling**.
