# Open Science Contributions and Resources

This page details the open science contributions, including software packages, shared data, and methodological resources developed by the group.

## 💻 Software Packages and Tools

This section lists specialized, peer-reviewed software packages and applications developed for statistical analysis.

### Peer-Reviewed Packages & Apps

- **ABrox** (Python Module)

  - **Description:** A user-friendly Python module for approximate Bayesian computation, with a focus on model comparison.
  - **Link:** [https://github.com/mertensu/ABrox](https://github.com/mertensu/ABrox)
  - **Reference:** Mertens, U. K., Voss, A., & Radev, S. (2018). *ABrox—A user-friendly Python module for approximate Bayesian computation with a focus on model comparison*. PLOS ONE, 13(3), e0193981. [https://doi.org/10.1371/journal.pone.0193981](https://doi.org/10.1371/journal.pone.0193981)

- **CurtailedRRT** (R Shiny App)

  - **Description:** Implements sequential hypothesis testing within a curtailed sampling plan using randomized response techniques.
  - **Link:** [https://fabiolareiber.shinyapps.io/CurtailedRRT/](https://fabiolareiber.shinyapps.io/CurtailedRRT/)
  - **Reference:** Reiber, F., Schnuerch, M., & Ulrich, R. (2020). *Improving the efficiency of surveys with randomized response models: A sequential approach based on curtailed sampling*. Psychological Methods. [doi.org/10.1037/met0000353](https://doi.org/10.1037/met0000353)

- **gpt** (R Package)

  - **Description:** Generalized processing tree models: Jointly modeling discrete and continuous variables.
  - **Link:** [https://github.com/danheck/gpt](https://github.com/danheck/gpt)
  - **Reference:** Heck, D. W., Erdfelder, E., & Kieslich, P. J. (2018). *Generalized processing tree models: Jointly modeling discrete and continuous variables*. Psychometrika, 83, 893–918. [doi.org/10.1007/s11336-018-9622-0](https://doi.org/10.1007/s11336-018-9622-0)

- **MCMCprecision** (R Package)

  - **Description:** Quantifying uncertainty in transdimensional Markov chain Monte Carlo using discrete Markov models.
  - **Link:** [https://github.com/danheck/MCMCprecision](https://github.com/danheck/MCMCprecision)
  - **Reference:** Heck, D. W., Overstall, A., Gronau, Q. F., & Wagenmakers, E. (2019). *Quantifying uncertainty in transdimensional Markov chain Monte Carlo using discrete Markov models*. Statistics & Computing, 29, 631–643. [doi.org/10.1007/s11222-018-9828-0](https://doi.org/10.1007/s11222-018-9828-0)

- **multinomineq** (R Package)

  - **Description:** Multinomial models with linear inequality constraints: Overview and improvements of computational methods for Bayesian inference.
  - **Link:** [https://github.com/danheck/multinomineq/](https://github.com/danheck/multinomineq/)
  - **Reference:** Heck, D. W., & Davis-Stober, C. P. (2019). *Multinomial models with linear inequality constraints: Overview and improvements of computational methods for Bayesian inference*. Journal of Mathematical Psychology, 91, 70–87. [doi.org/10.1016/j.jmp.2019.03.004](https://doi.org/10.1016/j.jmp.2019.03.004)

- **rtmpt** (R Package)

  - **Description:** An R package for fitting response-time extended multinomial processing tree models.
  - **Link:** [https://github.com/RaphaelHartmann/rtmpt](https://github.com/RaphaelHartmann/rtmpt)
  - **Reference:** Hartmann, R., Johannsen, L., & Klauer, K.C. (2020). *rtmpt: An R package for fitting response-time extended multinomial processing tree models*. Behavior Research Methods, 52, 1313–1338. [doi.org/10.3758/s13428-019-01318-x](https://doi.org/10.3758/s13428-019-01318-x)

- **SPRT t-tests** (R Script)

  - **Description:** Implements Abraham Wald's Sequential Probability Ratio Test.
  - **Link:** [https://osf.io/wz8da/](https://osf.io/wz8da/)
  - **Reference:** Schnuerch, M., & Erdfelder, E. (2020). *Controlling decision errors with minimal costs: The sequential probability ratio t-test*. Psychological Methods, 25(2), 206–226. [doi.org/10.1037/met0000234](https://doi.org/10.1037/met0000234)

### Packages without Formal Journal Publications

- **IPV** (R Package)

  - **Description:** Generates plots based on the item pool visualization concept for latent constructs.
  - **Link:** [https://github.com/NilsPetras/IPV](https://github.com/NilsPetras/IPV)
  - **Contributors:** Nils Petras, M. Dantlgraber

- **Waldian t tests** (R Shiny App)

  - **Description:** Sequential Bayesian t tests with predefined thresholds to control error probabilities.
  - **Link:** [https://martinschnuerch.shinyapps.io/Waldian-t-Tests/](https://martinschnuerch.shinyapps.io/Waldian-t-Tests/)
  - **Contributor:** Martin Schnuerch

- **WienR** (R Package)

  - **Description:** Calculates the partial derivatives of the first-passage time PDF and CDF with respect to all parameters of the Wiener diffusion model.
  - **Link:** [https://github.com/RaphaelHartmann/WienR](https://github.com/RaphaelHartmann/WienR)
  - **Contributors:** Raphael Hartmann, Karl Christoph Klauer

## 🚀 Other Open Science Initiatives

### “Many Analysts” Project

This project aims to examine differences between various research teams regarding statistical analyses and results given an equal specific research question and dataset.

- **Information:** [https://osf.io/hpd6b/?view_only=b2e936f5a6d34eda80e236c167b4004e](https://osf.io/hpd6b/?view_only=b2e936f5a6d34eda80e236c167b4004e)
- **Contributing Analysts:** Susanne Frick, Julian Quevedo Pütter, Marcel Schmitt, Marcel Schreiner

### Hack-a-thon: Building an Open Science Knowledge Base

At the SIPS Conference 2019, Luisa Horsten co-led this hack-a-thon, presenting [https://how-to-open.science/](https://how-to-open.science/) and inviting community participation.

- **Event Link:** [https://osf.io/xtqjy/](https://osf.io/xtqjy/)
- **Outcome:** The core team established an open educational resources hub: [https://www.oercommons.org/hubs/oskb](https://www.oercommons.org/hubs/oskb)
