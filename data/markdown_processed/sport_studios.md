# Sportstudios der Universität Mannheim

Dem Hochschulsport stehen mehrere Sportstudios zur Verfügung, die von der Universität Mannheim betrieben werden. Diese Studios werden überwiegend von Studierenden genutzt und zeichnen sich durch eine besondere, studentische „Community“-Atmosphäre aus.

Sie finden hier eine Übersicht der einzelnen Sportstätten:

## Verfügbare Sportstudios

- [D2 FitnessGym](https://www.uni-mannheim.de/sport/studios/d2-fitnessgym/)
- [N6 SkyStudio](https://www.uni-mannheim.de/sport/sportstaetten/n6-skystudio/)
- [55 CrossGym](https://www.uni-mannheim.de/sport/studios/55-crossgym/)
- [C7 YogaStudio](https://www.uni-mannheim.de/sport/sportstaetten/yogastudio-c7/)
