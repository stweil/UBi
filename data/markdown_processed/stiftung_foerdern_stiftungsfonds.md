# Stiftungsfonds

Ein Stiftungsfonds ist eine alternative Organisationsform für kleinere Vermögen. Durch die Bildung eines solchen Fonds in Händen eines Treuhänders können Sie dauerhaft einen bestimmten gemeinnützigen Zweck fördern.

**Funktionsweise:**
Die Stifterin oder der Stifter bestimmt die Einrichtung des Stiftungsfonds in einem Treuhandvertrag und übergibt das Vermögen an die Treuhänderin oder den Treuhänder (z.B. die Stiftung Universität Mannheim). Dieses Vermögen wird als Sondervermögen, buchhalterisch getrennt von anderen Vermögenswerten, geführt.

Die aus diesem Sondervermögen erwirtschafteten Erträge fließen der Einrichtung unter dem von der Stifterin oder dem Stifter bestimmten Namen zu.

**Wichtige Hinweise:**

- Ein Stiftungsfonds ist kein eigenes Steuersubjekt und kann daher keine eigenen steuerlich wirksamen Zuwendungsbestätigungen erteilen.
- Dies kann ausschließlich die Treuhänderin oder der Treuhänder als steuerbefreite gemeinnützige Einrichtung.
- Ein Stiftungsfonds stellt eine mögliche Alternative zur Errichtung einer eigenen Stiftung dar.

[Wenn dies eine Option für Sie wäre, dann sprechen Sie mit uns.](https://www.uni-mannheim.de/stiftung/ueber-uns/kontakt/)
