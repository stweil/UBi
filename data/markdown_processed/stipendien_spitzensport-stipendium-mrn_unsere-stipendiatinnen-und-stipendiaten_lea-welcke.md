# Lea Welcke

Lea Welcke ist Stipendiatin im Rahmen des Elite-Sports-Stipendiums der Region Rhein-Neckar.

### Profilübersicht

| Kriterium | Details |
| :--- | :--- |
| **Förderungsbeginn** | HWS 2020/2021 |
| **Sportart** | Eishockey |
| **Studium** | Psychologie |
| **Verein** | Mad Dogs Mannheim |

### Sportliche Erfolge

Lea Welcke hat folgende herausragende sportliche Erfolge vorzuweisen:

- **2022:** 2. Platz Deutsche Meisterschaft
- **2021:** 5. Platz 1. Bundesliga
- **2018:** Teilnahme Turnier Tokyo A Nationalmannschaft
- **2017:** 1. Platz Weltmeisterschaft D1 U18
- **2016:** 2. Platz Weltmeisterschaft D1 U18
