# Akkreditierung von Studiengängen

Wenn ein Studiengang akkreditiert ist, bedeutet dies, dass er bestimmten Qualitätsstandards entspricht. Die Akkreditierung fungiert somit als eine Art Qualitätssiegel für Studiengänge.

**Wichtig:** Ohne eine Akkreditierung kann ein Studiengang nicht an einer Hochschule oder Universität angeboten werden.
