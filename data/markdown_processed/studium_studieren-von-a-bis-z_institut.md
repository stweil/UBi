# Was ist ein Institut?

Ein Institut ist eine definierte Organisationseinheit innerhalb einer Hochschule oder Fakultät.

**Funktion:**
Einem Institut können thematisch zusammengehörige Lehrstühle einer Fakultät zugeordnet sein, wodurch ein Oberbegriff für ein spezifisches Studiengebiet entsteht.
