# Kolloquium

Der Begriff „Kolloquium“ kann verschiedene Bedeutungen haben:

- Es kann eine Diskussionsrunde zu speziellen wissenschaftlichen Themen gemeint sein.
- Eine Veranstaltung zur Vertiefung des Stoffes einer Vorlesung.
- Ein Prüfungsgespräch, das als Leistungsnachweis dient.
