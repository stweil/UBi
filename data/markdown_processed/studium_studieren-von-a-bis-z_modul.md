# Modul an der Universität Mannheim

Ein Modul ist eine definierte Lehreinheit, die aus einer oder mehreren einzelnen Lehrveranstaltungen besteht.

**Arten von Modulen:**

- **Pflichtmodule:** Diese Module müssen von Studierenden belegt werden.
- **Wahlpflichtmodule:** Diese Module können aus einem thematisch eingegrenzten Bereich frei gewählt werden.
