# Studienplan

Der Studienplan beschreibt den empfohlenen Aufbau Ihres Studiums.

Wer sich an den darin aufgeführten Zeitplan hält, kann sein Studium in der jeweiligen [Regelstudienzeit](https://www.uni-mannheim.de/studium/studieren-von-a-bis-z/regel-studien-zeit/) erfolgreich absolvieren.

Für eine allgemeine Übersicht zum Thema Studium finden Sie hier: [Studieren verstehen](https://www.uni-mannheim.de/studium/studieren-von-a-bis-z/)
