# Landesprogramme: Akademischer Austausch ins Ausland

Landesprogramme sind multilaterale Kooperationen zwischen den **baden-württembergischen Hochschulen** und einem Verbund öffentlicher Hochschulen eines **amerikanischen Bundesstaates** (z. B. das California State University System oder das North Carolina State University System).

Auf baden-württembergischer Seite werden diese Programme vom Ministerium für Wissenschaft, Forschung und Kunst (MWK) koordiniert und mitfinanziert. Da an einem Austausch über ein Landesprogramm mehrere baden-württembergische Hochschulen beteiligt sind, ist eine genaue Absprache und Koordination zwischen den verschiedenen Campus erforderlich. Für jedes Landesprogramm gibt es eine koordinierende Universität auf baden-württembergischer und eine auf nordamerikanischer Seite.

## Bewerbungsverfahren

Das Verfahren gliedert sich in zwei Hauptschritte:

### 1. Grundsätzliche Bewerbung und Zusage

Zunächst bewerben Sie sich generell an der Universität Mannheim um die Teilnahme an einem Landesprogramm. Die Bewerbung erfolgt über die regulären [Auslandsbewerbungstermine](https://www.uni-mannheim.de/studium/von-mannheim-ins-ausland/austauschstudium/bewerbung/bewerbungsanleitungen/) der Universität Mannheim. Sie können in dieser Bewerbung mehrere Wunschziele aus verschiedenen Regionen angeben und dabei auch Partneruniversitäten und Landesprogramme mischen.

### 2. Platzierung innerhalb des Landesprogramms

Nach Erhalt einer **Zusage für die Teilnahme** erfolgt in einem zweiten Schritt die **Platzierung an einer Universität** innerhalb des Landesprogramms. Hier können Sie Ihre bevorzugten Universitäten nennen. Die Platzierung wird von einer Kommission des Landesprogramms zusammen mit den ausländischen Universitäten entschieden. Es wird versucht, Sie an einer Ihrer Wunschuniversitäten zu platzieren; falls dies nicht möglich ist, wird Ihnen garantiert ein geeigneter Platz für Ihr Studienfach an einer anderen Universität angeboten.

**Empfehlung:**
Aufgrund der komplexen Struktur und der vielen Details der Landesprogramme ist eine Beratung im **Akademischen Auslandsamt** vor der Bewerbung unerlässlich.
