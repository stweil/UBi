# Orientierungstests für die Studienwahl

Ein Orientierungstest kann bei der Entscheidung für ein Studium unterstützen. **Wichtig:** Für die eigentliche Bewerbung ist kein Orientierungstest notwendig. Sie benötigen diesen Nachweis erst, wenn Sie eine Zulassung für einen Bachelorstudiengang erhalten und diesen Studienplatz annehmen möchten. Auf dem Nachweis wird lediglich bestätigt, dass Sie einen der notwendigen Orientierungstests absolviert haben.

## Übersicht der verfügbaren Tests

Je nach Studienfach und Ziel können verschiedene Tests relevant sein.

### 1. Was studiere ich? (Ministerium für Wissenschaft, Forschung und Kunst Baden-Württemberg)

Dieser Test hilft dabei herauszufinden, welches Studium zu Ihnen passt. Nach dem Test erhalten Sie ein Teilnahme-Zertifikat.

- [Was studiere ich?](http://www.was-studiere-ich.de/)

### 2. Studium-Interessentest (SIT)

Alternativ akzeptiert wird auch der Nachweis über den [Studium-Interessentest (SIT)](https://www.hochschulkompass.de/studium-interessentest) der Hochschulrektorenkonferenz.

### 3. Check-U (Agentur für Arbeit)

Die Agentur für Arbeit bietet einen umfangreichen Orientierungstest [Check-U](https://www.arbeitsagentur.de/bildung/welche-ausbildung-welches-studium-passt) an, der bei der Studienorientierung helfen kann.

### 4. Lehrerorientierungstest (Für Lehramt)

Wenn Sie sich für ein Lehramts- oder Wirtschaftspädagogik-Studium einschreiben möchten, müssen Sie den [Lehrerorientierungstest](https://mwk.baden-wuerttemberg.de/de/hochschulen-studium/lehrerbildung/lehrerorientierungstest-fuer-studieninteressierte/) einreichen.

### 5. Online Self-Assessment (OSA) – OSA Psych

Für den Studiengang Bachelor Psychologie ist es erforderlich, einen Nachweis über den [OSA-Psych](https://www.osa-psych.de/) hochzuladen.
