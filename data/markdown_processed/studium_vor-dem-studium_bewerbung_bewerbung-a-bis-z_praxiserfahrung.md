# Auflistung außerschulischer Tätigkeiten in der Onlinebewerbung

Bei der Onlinebewerbung werden Sie aufgefordert, alle außerschulischen Tätigkeiten (Praktika, Jobs, Ehrenämter etc.) einzutragen.

## Allgemeine Richtlinien für die Eingabe

- **Angaben:** Bitte geben Sie für jede Beschäftigung den genauen Zeitraum sowie den möglichst genauen Stundenaufwand pro Woche an.
- **Nachweis:** Es dürfen **nur Tätigkeiten angegeben werden, die durch entsprechende Belege nachweisbar sind**. Diese Belege müssen den Zeitraum und die genaue Tätigkeit enthalten.
- **Dokumentation:** Wir stellen Standardbelege in deutscher und englischer Sprache zur Verfügung. Diese müssen von Ihrem Arbeitgeber gestempelt und unterschrieben werden.
- **Ausland/Abschluss:** Geben Sie bitte an, ob die Tätigkeit im Ausland erbracht wurde oder ob es sich um eine abgeschlossene Ausbildung handelt.

## Kategorien der Tätigkeiten

Wählen Sie die passende Kategorie für Ihre Tätigkeit aus dem Menü aus.

### 🎓 Studium und Ausbildung

- **Berufsausbildung:** Geben Sie an, ob die Ausbildung erfolgreich abgeschlossen wurde (Ja/Nein). Ein entsprechender Nachweis ist bei einem abgeschlossenen Abschluss erforderlich.
- **DHBW/Duales Studium:** Wählen Sie diese Kategorie, wenn Sie sich aktuell oder bereits in einem DHBW/Dualen Studium befanden.
- **Pflichtpraktikum:** Tragen Sie hier ein, wenn Sie ein Pflichtpraktikum im Rahmen eines (Vor-) Studiums absolviert haben.
- **Praktikum:** Wählen Sie dies für jegliche entgeltliche oder unentgeltliche Tätigkeit, die als Praktikum ausgewiesen ist. Dies gilt unabhängig davon, ob die Tätigkeit bei privaten, öffentlichen oder gemeinnützigen Einrichtungen ausgeübt wurde.
- **Beruf:** Wählen Sie diese Kategorie, wenn Sie nach einer abgeschlossenen Berufsausbildung in diesem Beruf tätig waren. Bitte fügen Sie eine Kopie Ihres Arbeitszeugnisses bei.
- **praktische Abschlussarbeit:** Falls Ihre Abschlussarbeit in einem Unternehmen verfasst wurde.

### 💼 Beschäftigung und Engagement

- **Job:** Wählen Sie dies für Tätigkeiten, die gegen Entgelt ausgeübt wurden (z. B. Kellnern, Verkauf, Postverteilung). Dies gilt unabhängig vom Träger (privatwirtschaftlich, öffentlich etc.).
- **Ehrenamtliches Engagement:** Für unentgeltliches Engagement (z. B. Umweltschutzorganisationen, Jugendarbeit, Parteiarbeit).
- **Beruf:** (Siehe oben)
- **Schulische Sonderleistungen:** Für besondere Leistungen während der Schulzeit, die über den Unterricht hinausgingen (z. B. Teilnahme an einer AG, Schülerfirma).
- **Wehr- oder Zivildienst / Freiwilliges soziales/ökologisches Jahr:** Hier muss ein entsprechender Nachweis erbracht werden. *Hinweis: Die bevorzugte Berücksichtigung bei der Vergabe von Studienplätzen erfolgt gesondert.*
- **Sonstiges:** Für alle Tätigkeiten, die nicht in die genannten Kategorien passen.

## Zuordnung der Tätigkeitsbereiche

Bei der Angabe außerschulischer Tätigkeiten müssen Sie diese zudem bestimmten Fachbereichen zuordnen. Es ist prinzipiell ausreichend, die Tätigkeit einem Bereich zuzuordnen, aber bei Überschneidungen können beide Dropdown-Felder genutzt werden.

| Fachgebiet | Beschreibung der Tätigkeiten |
| :--- | :--- |
| **Informatik** | Programmierung, Web-Service und -Design, Datenbankpflege, EDV-Service, Informationsmanagement etc. |
| **Journalismus/PR** | Redaktionelle Tätigkeiten, Schülerzeitung, Presse, Radio, Fernsehen, Werbung, Öffentlichkeitsarbeit etc. |
| **Kultur** | Tätigkeiten im Bereich Theater, Museum, Galerie etc. |
| **Lehre** | Tutorin oder Tutor, Dozentin oder Dozent, Erwachsenenbildung, Weiterbildung etc. |
| **Politik** | Tätigkeiten im Bereich Öffentliche Verwaltung, Friedensarbeit, Gewerkschaft, Verbände etc. |
| **Recht** | Tätigkeiten bei Anwälten, Notariaten, Rechtsabteilungen, Botschaften oder als Rechtsanwaltsfachangestellte etc. |
| **Wirtschaft** | Bank, Versicherung, Groß- und Einzelhandel, Außenhandel, kaufmännische Tätigkeiten, Tourismus, Marktforschung, Marketing, Vertrieb, Personal, Organisation, Finanzwesen etc. |
| **Soziales/Gesundheit** | Jugendarbeit, Behindertenbetreuung, Kinder- und Jugendeinrichtungen, Entwicklungsarbeit, Politik, Beratungsstellen, Krankenpflege etc. |
| **Unklare Zuordnung** | Nicht in die obenstehenden Bereiche einsortierbar, jedoch mit Bezug zum Wunschstudium. |
| **Sonstiges** | Kassier-/Servicetätigkeiten, Babysitten, Gastronomie, Promotionsjobs etc. |
