# TOEFL: Englischkenntnisse für Ihr Studium

Der **Test of English as a Foreign Language (TOEFL)** ist ein standardisierter Sprachtest, der die Englischkenntnisse von Nicht-Muttersprachler\*innen überprüft. Für einige Studiengänge an der Universität Mannheim ist ein entsprechender TOEFL-Test mit einer bestimmten Punktzahl erforderlich.

## Wichtige Hinweise zur Testabgabe

- **Testcenter:** Eine Übersicht der zugelassenen Testcenter finden Sie auf der Website des jeweiligen Anbieters.
- **Akzeptierte Formate:** Die **TOEFL iBT Home Edition** wird ebenfalls für Ihre Bewerbung akzeptiert.
- **Direkte Übermittlung:** Wenn Sie einen TOEFL iBT ablegen und das Ergebnis direkt an die Zulassungsstelle der Universität Mannheim senden lassen möchten, verwenden Sie bitte den **Institution Code 0254**.
- **Gültige Ergebnisse:** Bitte beachten Sie, dass für Ihre Bewerbung ausschließlich die **Test Date Scores** relevant sind. Mybest Scores werden nicht berücksichtigt.

Für allgemeine Informationen zum Bewerbungsprozess lesen Sie bitte unsere Übersicht: [Bewerbung von A bis Z: Von A wie Amtliche Beglaubigung bis Z wie Zulassungsantrag](https://www.uni-mannheim.de/studium/vor-dem-studium/bewerbung/bewerbung-a-bis-z/)
