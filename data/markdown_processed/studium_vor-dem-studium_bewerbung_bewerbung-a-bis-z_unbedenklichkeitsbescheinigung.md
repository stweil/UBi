# Unbedenklichkeitsbescheinigung

Die Unbedenklichkeitsbescheinigung ist ein wichtiges Dokument, wenn Sie bereits Vorstudienzeiten an einer deutschen Hochschule absolviert haben. Sie dient als Nachweis dafür, dass Ihr **Prüfungsanspruch** noch besteht.

### Wann wird die Bescheinigung benötigt?

Sie benötigen diese Bescheinigung in folgenden Situationen:

- Wenn Sie bereits Vorstudienzeiten an einer deutschen Hochschule hatten und sich für ein höheres Fachsemester bewerben.
- Auch wenn Sie bereits an einer deutschen Hochschule eingeschrieben waren und sich bei uns in das erste Fachsemester eines ähnlichen Studiengangs bewerben.

### Das Verfahren

Es gibt kein standardisiertes Verfahren für die Ausstellung dieser Bescheinigung:

- Einige Hochschulen bestätigen den Prüfungsanspruch direkt auf dem Notenauszug.
- Andere Hochschulen erstellen hierfür ein gesondertes, separates Schreiben.

Für die Bestätigung können Sie einen Musterordner nutzen, der unter [Bewerbung von A bis Z](https://www.uni-mannheim.de/studium/vor-dem-studium/bewerbung/bewerbung-a-bis-z/) zu finden ist.
