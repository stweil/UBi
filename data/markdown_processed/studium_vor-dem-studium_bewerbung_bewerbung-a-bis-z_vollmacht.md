# Vollmacht bei der Bewerbung

## Allgemeine Regelungen

Sie können sich für einen Studienplatz bei der Universität Mannheim bewerben, auch wenn Sie noch nicht volljährig sind. In diesem Fall benötigen Sie weder die Unterschrift Ihrer Eltern noch eine Vollmacht.

## Wann ist eine Vollmacht notwendig?

Eine Vollmacht ist **nur dann** erforderlich, wenn Sie wünschen, dass eine andere Person Sie vertritt.

**Wichtig:** Ohne eine vorliegende Vollmacht können Dritte (wie beispielsweise Ihre Eltern) weder Informationen zu Ihrer Bewerbung erhalten noch Ihre Einschreibung vornehmen.

## Einreichung

Falls Sie eine Vertretung wünschen, reichen Sie die Vollmacht zusammen mit Ihren übrigen Bewerbungsunterlagen ein.
