# Beratungstermine Nadja Kindinger (Incoming Austauschstudierende)

Die Beratung zu Themen für Incoming Austauschstudierende kann auf zwei Wegen erfolgen:

- **Digitale Beratung:** Über Microsoft Teams. Nach der Buchung erhalten Sie eine Bestätigungs-E-Mail mit allen weiteren Details.
- **Persönliche Beratung:** Es stehen nur eine beschränkte Anzahl an persönlichen Beratungsterminen zur Verfügung. Diese können Sie direkt über den Kalender buchen.
